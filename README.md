# Steven Gilbert — Provider Data Business Analyst

A standalone provider data portfolio. No npm, Node.js, or build step is needed.

## Publish

1. Create a public GitHub repository named `steven-gilbert-provider-data`.
2. Upload `index.html`, `style.css`, and `site.js` directly to the repository root. Do not upload the enclosing download folder or ZIP file.
3. Upload this README if desired.
4. Create `.github/workflows/deploy-pages.yml` using GitHub's Add file > Create new file. Paste the included workflow text and commit to main.
5. In Settings > Pages, select GitHub Actions as the source.
6. In Actions, run Deploy provider portfolio to GitHub Pages if it has not started automatically.
7. After deployment succeeds, open https://notsogilbert.github.io/steven-gilbert-provider-data/.

## Update

Edit the root-level website files and commit to main. The workflow republishes automatically. Keep the three upcoming projects labeled as planned until their evidence is completed.
